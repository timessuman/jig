Typography

Measure and grid

Long-form text is measure-capped. The grid is 12 columns with a mode-selected gutter and margin.

Prose is capped at --measure-prose so the eye can find the next line. This paragraph is exactly that wide. Below 40 characters the eye returns too often; above 80 it loses the line, which is why the measure is a per-mode selection rather than one value.

Motion

Hover a swatch. Durations and easings are mode-selected; all resolve to 1ms under prefers-reduced-motion.

Spacing roles

Named roles select from the shared ladder. These are what components reference, not the raw steps.

Touch target

The hit area is --size-touch-target in every mode, even where the drawn control is shorter.

Diagnostics

Raw channel inputs and the active mode marker. Not for use at a call site — shown so a wrong value is visible rather than inferred.
